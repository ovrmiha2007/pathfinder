# Pathfinder

Клиентский NeoForge-мод (Minecraft **1.21.11**) — визуальный редактор **нод** и бот: добыча, крафт, постановка блоков, навигация.

Собираешь схему из нод (добыть → скрафтить → поставить → конец), бот сам ходит и выполняет граф логики.

**Автор:** ovrmiha

## Возможности

- Редактор нод (`[`): полотно, связи, схемы save/load
- Ноды: Старт, Зона, Чит, Паралельно, Если, Добыть, Скрафтить, Поставить, Йти до, Йти в, Переслідувати, Обстежити, Конец, …
- Зона работы: центр+радиус или от XYZ₁ до XYZ₂
- Нода **Чит**: усі чанки в пам'яті клієнта, цілі крізь стіни, pathfinding з цією інфою
- **Переслідувати** гравця/сутність · **Йти в** XYZ · **Обстежити** радіус · **Паралельно** — дод. задача «коли можна»
- Крафт 2×2 / 3×3 с ожиданием сервера
- Команды: `/ls`, `/pf`, `/pathfinder`

## Версии

| Изменение | Версия | GitHub |
|-----------|--------|--------|
| Мелкий фикс / полировка | `+0.0.0.1` → `1.4.9.1` | **beta** (prerelease) |
| Нормальная фича / заметный апдейт | `+0.0.1` → `1.5.0` | **stable** (Latest) |

Каждая версия → отдельный [Release](https://github.com/ovrmiha2007/pathfinder/releases) с JAR.

```bash
# после bump mod_version в gradle.properties + ModVersion.java
./scripts/release.sh
```

## Происхождение кода

Часть логики навигации, взгляда и движения **позаимствована у [Baritone](https://github.com/cabaletta/baritone)** (идеи / подходы pathfinding и rotation helpers). Спасибо авторам Baritone.

## Сборка

```bash
./gradlew build
```

JAR: `build/libs/pathfinder-<version>.jar` → папка `mods/` (NeoForge 1.21.11).

## Управление

| Клавиша / команда | Действие |
|-------------------|----------|
| `[` | Редактор нод |
| `J` | Стоп |
| `/ls logic` | Открыть редактор |
| `/ls stop` | Остановить бота |

Схемы: `.minecraft/pathfinder/schemes/`
