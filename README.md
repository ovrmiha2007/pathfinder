# Pathfinder

Клиентский NeoForge-мод (Minecraft **1.21.11**) — візуальний редактор **нод** і бот: добування, крафт, постановка блоків, навігація.

**Автор:** ovrmiha

## Можливості

- Редактор нод (`[`): полотно, зв’язки, схеми save/load
- Ноди: Старт, Зона, Якщо, Добути, Скрафтити, Поставити, Кінець, …
- Зона роботи: центр+радіус або від XYZ₁ до XYZ₂
- Крафт 2×2 / 3×3 з очікуванням сервера
- Команди: `/ls`, `/pf`, `/pathfinder`

## Збірка

```bash
./gradlew build
```

JAR: `build/libs/pathfinder-<version>.jar` → папка `mods/` (NeoForge 1.21.11).

## Керування

| Клавіша / команда | Дія |
|-------------------|-----|
| `[` | Редактор нод |
| `J` | Стоп |
| `/ls logic` | Відкрити редактор |
| `/ls stop` | Зупинити бота |

Схеми: `.minecraft/pathfinder/schemes/`
